# 每日错题复习程序

基于**艾宾浩斯遗忘曲线**的数学错题复习管理工具，自动推荐每天该复习的错题。

## 快速开始

双击 `每日错题程序.html`，在浏览器中打开即可使用。无需安装任何软件。

## 核心功能

- **🎯 智能推荐** — 打开即显示今天该复习的错题，按逾期天数降序 + 复习次数升序排序
- **➕ 添加/批量导入** — 支持逐个添加和从文件批量导入已有错题
- **✅ 完成复习** — 根据艾宾浩斯曲线自动计算下次复习日期
- **📊 统计面板** — 总错题数 / 今日待复习 / 今日已复习
- **📤 数据导出/导入** — JSON 格式，可换设备或备份
- **⌨️ 快捷键** — `Enter` 完成复习，`空格/→` 跳过

## 艾宾浩斯复习间隔

| 复习次数 | 间隔天数 |
|---------|---------|
| 第 1 次 | 1 天 |
| 第 2 次 | 2 天 |
| 第 3 次 | 4 天 |
| 第 4 次 | 7 天 |
| 第 5 次 | 15 天 |
| 第 6 次及以后 | 30 天 |

## 批量导入格式

点击 **📝 批量导入**，粘贴错题数据，每行一个：

```
题号 复习次数
```

示例：

```
二次函数-顶点式 3
向量-夹角公式 1
概率-条件概率 0
立体几何-证明 5
```

支持的列分隔符：空格、逗号、Tab、中文逗号。

## 数据存储

数据保存在浏览器 `localStorage` 中，在电脑上持久保存，关闭浏览器不会丢失。

### 两个存储键

| Key | 内容 |
|-----|------|
| `mistake_problems` | 所有错题数组（JSON） |
| `reviewed_today` | 今日已复习的错题 ID 列表，跨天自动重置 |

### 查看/修改数据

打开 F12 → Application → Local Storage → `file://`

### 换设备迁移

导出 JSON → 新设备导入 JSON。

## 数据模型

```json
{
  "id": "uuid",
  "index": "题号/名称",
  "reviewCount": 3,
  "lastReviewDate": "2026-06-06",
  "nextReviewDate": "2026-06-10",
  "dateAdded": "2026-06-01"
}
```

## 推荐使用方式

1. 用 Python 启动本地服务器，避免 `file://` 路径变动导致数据丢失：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080/每日错题程序.html`。

2. 定期导出 JSON 备份。
